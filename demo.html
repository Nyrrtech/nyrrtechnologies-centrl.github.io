Integration

Add to any website

Paste these two lines before the closing </body> tag:

<link rel="stylesheet" href="accessibility-widget.css">
<script src="widget-core.js"></script>
<script src="widget-ui.js"></script>

Then set your Mistral API key inside the widget Settings tab to enable AI features.

Why Web Accessibility Matters

Over one billion people worldwide live with some form of disability. The web should be usable by everyone, regardless of visual, auditory, motor, or cognitive ability. Despite this, many websites are built without accessibility in mind, creating barriers for a significant portion of the population.

AccessKit removes those barriers with a single embed. It brings assistive technology features directly to your users without requiring them to install browser extensions or use separate software.

Built on Open Standards

The widget uses the Web Speech API for text-to-speech, CSS custom properties for theming, and the Mistral AI API for intelligent features. Everything runs in the browser — no data is collected, and no tracking occurs. Your users' privacy is respected.

All accessibility preferences are saved in localStorage so returning visitors get their preferred settings automatically applied from the first moment the page loads.
